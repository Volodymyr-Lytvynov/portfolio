# Portfolio Website

A modern, responsive single-page portfolio website built with HTML, CSS, and JavaScript.

## Project Structure

```
PORTFOLIO/
├── index.html          # Main HTML file
├── styles.css          # CSS styles
├── script.js           # JavaScript functionality
├── README.md           # Project documentation
└── assets/             # Asset folder
    ├── images/         # Image files
    ├── icons/          # Icon files
    └── fonts/          # Font files
```

## Features

- **Responsive Design**: Works on desktop, tablet, and mobile devices
- **Smooth Scrolling**: Navigation links smoothly scroll to sections
- **Mobile Navigation**: Hamburger menu for mobile devices
- **Interactive Elements**: Hover effects, animations, and form validation
- **Modern UI**: Clean, professional design with gradient backgrounds
- **Contact Form**: Functional contact form with validation
- **Scroll Animations**: Elements animate into view when scrolled to

## Sections

1. **Hero Section**: Introduction with name, title, and call-to-action buttons
2. **About Section**: Personal information and background
3. **Projects Section**: Portfolio of work (grid layout)
4. **Skills Section**: Technical skills and abilities
5. **Contact Section**: Contact information and form

## Technologies Used

- HTML5 (semantic markup)
- CSS3 (Grid, Flexbox, animations, responsive design)
- Vanilla JavaScript (DOM manipulation, event handling, form validation)

## Getting Started

1. Open `index.html` in a web browser
2. Customize the content in the HTML file
3. Modify styles in `styles.css`
4. Add your images to the `assets/images/` folder
5. Update the JavaScript in `script.js` if needed

## Customization

### Adding Content
- Replace placeholder text in `index.html`
- Add your project information in the projects section
- Update contact information
- Add your skills and technologies

### Styling
- Modify colors in `styles.css` (search for color values)
- Adjust fonts and typography
- Change layout spacing and sizing
- Add custom animations

### Images
- Add profile photo to `assets/images/`
- Add project screenshots
- Update image references in HTML
